# CuePipe

Android app, package `app.cuepipe`. `./gradlew :app:test` runs the host tests. `./gradlew :app:assembleDebug` writes the debug APK.

## Tools

Run a long or noisy shell command through `rtk`. When the context-mode server is connected, search this repo with it before a wide grep. For a second pass on a diff, a parser, or a failing test, ask the local model `qwen2.5-coder:14b` at `http://127.0.0.1:11434`. There is no `qwen` binary on `PATH`.

Read the skill that matches the work before editing. ponytail for a new abstraction or dependency. writing-for-agents for this file. sanitizers when C is added.

## Index

Search is SQLite FTS4, external content. A hit's place is `offsets(fts)`, a byte into the transcript. The span that contains that byte has the seek time. `matchinfo(fts, 'pcnalx')` is the ranking input, the same blob Grove parses.

## Slice

The shell is Home, Library, and Downloads. Home searches a service. A video opens on its own page: player, caption controls, and the transcript. Back leaves that page. Library lists the transcripts on the device. It sorts by newest, title, or channel, and filters by service. Its search is FTS4 across every track. Reader shows the open transcript. A tap jumps to Watch and seeks that cue. Explore searches a NewPipeExtractor service and opens a channel's videos and playlists, or a playlist's videos. A long press bookmarks that item. The list is the first page only. Watch fetches a URL, plays it, and keeps the captions. On screen captions are a switch, off until turned on. A cue asks the extractor for a fresh stream, or plays the file from Keep. Fuzzy and Concepts expand the library query. Meaning is a library switch. It fetches e5-small-v2 once into app files and ranks paragraph vectors from the vec table, including a line that does not contain the query words. The model is English WordPiece. Stemming is the porter tokenizer. Explore has a next page, and Check lists new videos from bookmarked channels and playlists. The YouTube home feed is the music, movies, and gaming charts, labeled Trending. The old combined Trending tab no longer parses. Live is the fallback when those charts are missing. Home keeps Bookmarks and Check under the search box. Back and More sit with the list. The video name stays in the title. Progress and errors use the status line under it. Keep, Burned-in, Recognize, On screen, and Translate are named. Translate writes another track with the same times. Check fetches each new video from a bookmark. A later fetch keeps an edited track and drops only unedited captions. Paragraphs groups the open transcript into sentences with a timestamp heading. Each other selected language is a smaller paragraph under that one, over the same time. The line list stays available. The transcript list follows the playhead. A tap seeks the prepared player. Dragging the list pauses that follow until the next tap or player seek. Description, the four caption menus, and find sit behind Details, closed at first, so the list keeps the room under the player. Burned-in reads the bottom of a kept file with ML Kit. Recognize decodes a kept file and runs whisper.cpp tiny, downloaded once into app files. A picture file with no audio track gets a separate audio download that is not stored as the Keep file. Meaning and subscriptions are later slices.
