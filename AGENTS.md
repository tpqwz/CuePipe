# cuepipe

Android app, package `app.cuepipe`. `./gradlew :app:test` runs the host tests. `./gradlew :app:assembleDebug` writes the debug APK.

## Tools

Run a long or noisy shell command through `rtk`. When the context-mode server is connected, search this repo with it before a wide grep. For a second pass on a diff, a parser, or a failing test, ask the local model `qwen2.5-coder:14b` at `http://127.0.0.1:11434`. There is no `qwen` binary on `PATH`.

Read the skill that matches the work before editing. ponytail for a new abstraction or dependency. writing-for-agents for this file. sanitizers when C is added.

## Index

Search is SQLite FTS4, external content. A hit's place is `offsets(fts)`, a byte into the transcript. The span that contains that byte has the seek time. `matchinfo(fts, 'pcnalx')` is the ranking input, the same blob Grove parses.

## Slice

The shell is Home, Library, and Downloads. Home searches a service. A video opens on its own page: player, caption controls, and the transcript. Back leaves that page. Library lists the transcripts on the device. It sorts by newest, title, or channel, and filters by service. Its search is FTS4 across every track. Reader shows the open transcript. A tap jumps to Watch and seeks that cue. Explore searches a NewPipeExtractor service and opens a channel's videos and playlists, or a playlist's videos. A long press bookmarks that item. The list is the first page only. Watch fetches a URL, plays it, and keeps the captions. On screen captions are a switch, off until turned on. A cue asks the extractor for a fresh stream, or plays the file from Keep. Fuzzy and Concepts expand the library query. Stemming is the porter tokenizer. Explore has a next page, and Check lists new videos from bookmarked channels and playlists. Burned-in reads the bottom of a kept file with ML Kit. Meaning, a Whisper model, and subscriptions are later slices.
