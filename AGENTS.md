# CuePipe

Android app, package `app.cuepipe`. `./gradlew :app:test` runs the host tests. `./gradlew :app:assembleDebug` writes the debug APK.

## Tools

Run a long or noisy shell command through `rtk`. When the context-mode server is connected, search this repo with it before a wide grep. For a second pass on a diff, a parser, or a failing test, ask the local model `qwen2.5-coder:14b` at `http://127.0.0.1:11434`. There is no `qwen` binary on `PATH`.

Read the skill that matches the work before editing. ponytail for a new abstraction or dependency. writing-for-agents for this file. sanitizers when C is added.

## Index

Search is SQLite FTS4, external content. A hit's place is `offsets(fts)`, a byte into the transcript. The span that contains that byte has the seek time. `matchinfo(fts, 'pcnalx')` is the ranking input, the same blob Grove parses.

## Slice

The shell is Home, Library, and Downloads. Home searches a service. A video opens on its own page: player, caption controls, and the transcript. Back leaves that page. Library lists the transcripts on the device. It sorts by newest, title, or channel, and filters by service. Its search is FTS4 across every track. Reader shows the open transcript. A tap jumps to Watch and seeks that cue. Explore searches a NewPipeExtractor service and opens a channel's videos and playlists, or a playlist's videos. A long press bookmarks that item. The list is the first page only. Watch fetches a URL, plays it, and keeps the captions. On screen captions are a switch, off until turned on. A cue asks the extractor for a fresh stream, or plays the file from Keep. Fuzzy and Concepts expand the library query. Meaning is a library switch. It fetches e5-small-v2 once into app files and ranks paragraph vectors from the vec table, including a line that does not contain the query words. The model is English WordPiece. Stemming is the porter tokenizer. Explore has a next page, and Check lists new videos from bookmarked channels and playlists. The YouTube home feed is the music, movies, and gaming charts, labeled Trending. The old combined Trending tab no longer parses. Live is the fallback when those charts are missing. A side drawer replaces the bottom bar. It holds Home, Library, Downloads, Subscriptions, Bookmarks, Check, and the service. A pasted RSS or feed URL opens a podcast. BitChute is a service in the drawer, learned from the Grayjay plugin's public JSON: popular, search, a channel, and a pasted video. The media call returns one MP4. That video has no caption file, so Keep and Recognize still apply. Bilibili is a service in that drawer. Its play URL is WBI-signed. The picture and the audio are separate files, and the CDN wants a Bilibili Referer. Subtitles need a login, so that video has no caption file either. Recognize downloads the separate audio when the kept picture has no sound. Niconico is the service after it. A watch page embeds the media list, and a POST returns one HLS playlist. Playback sends the nicosid cookie from that page. The plugin's v1 search returns 404, so search uses v2. Live streams stay out. Rumble's watch page and embedJS are behind Cloudflare. A watch link's oEmbed points at the embed page, and that page carries the same mp4 list. The feed and search stay blocked. Paste a video link. Kick is the next service. Home and search are livestreams from the plugin's web API. A channel link plays that channel's playback URL, which is HLS. A channel that is not live has no stream. Saved videos are not opened. Odysee is the next service. A free stream is the v6 file from odysee-api, `player.odycdn.com/v6/streams/{claim}/{sdHash6}.mp4`, with an Odysee Referer. Members-only, unlisted, purchase, and rental claims are refused. FOSDEM is the next service. Talks come from the Grayjay plugin's opensource-tv API. The file is the mp4 mirror, and a WebVTT track on the talk is saved as captions. Internet Archive is the next service. Home is popular movies from advancedsearch. A details link opens `/metadata/{id}` and plays one video file. An SRT or VTT on the item is saved as captions. TED is the next service. Home and a talk come from the Grayjay plugin's GraphQL query. Search uses www.ted.com/api/search. Auto plays the high MP4, 720 the medium file, 360 the low file. A WebVTT from the HLS metadata is saved as captions. NASA+ is the next service. Videos come from the Grayjay plugin's WordPress route. The file is the HLS url in meta.video-url. There is one stream and no caption file. Red Bull TV is the next service. The feed needs a browser user agent. Playback is the player API's HLS url, and an English VTT is saved when the asset id is present. A Podcast 2.0 transcript becomes a caption track. An episode with none still plays, and Keep downloads that audio so Recognize can run Whisper. Playback runs in PlayService, so a stream or a kept file keeps going with the screen off. The activity only attaches the view. A thin red progress line stays on the picture after the player controls fade. Quality in the Player menu switches Auto, 360p, 720p, or Audio and stays at the current moment. A picture without its own audio is played with a separate audio stream. Mini, next to Player, shrinks the picture to a small window so the transcript keeps the page. Player, next to Subtitles, sets speed (0.5× to 2×) and a subtitle offset. A positive offset shows each cue later. Stored times stay put. Subtitles on the video page opens the language list. Up to four can be on at once. A long press on a line or a paragraph offers Play here, Save excerpt, and Share. Play here uses a kept file when there is one, and otherwise opens a fresh stream. Excerpts in the side menu lists the saved lines. Follow on a video marks that channel. Check fetches new videos from followed channels and saved playlists. Search stays on the feed. Back and More sit with the list. The video name stays in the title. Progress and errors use the status line under it. Keep, Burned-in, Recognize, On screen, and Translate are named. Translate writes another track with the same times. Check fetches each new video from a bookmark. A later fetch keeps an edited track and drops only unedited captions. Paragraphs groups the open transcript into sentences with a timestamp heading. Each other selected language is a smaller paragraph under that one, over the same time. The line list stays available. The transcript list follows the playhead. A tap seeks the prepared player. Dragging the list pauses that follow until the next tap or player seek. Description, the four caption menus, and find sit behind Details, closed at first, so the list keeps the room under the player. Burned-in reads the bottom of a kept file with ML Kit. Recognize decodes a kept file and runs whisper.cpp tiny, downloaded once into app files. A picture file with no audio track gets a separate audio download that is not stored as the Keep file. Meaning and subscriptions are later slices.
